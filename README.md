# Portfolio_website

This repository contains the portfolio website for Ashok Talluri.

## Contents

- `index.html`: Main portfolio page
- `photo.jpg.jpg`: Profile image used in the website

## How to push

Run the following commands from the project folder:

```bash
git init
git add README.md index.html photo.jpg.jpg
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/ashoktalluri09-stack/Portfolio_website.git
git push -u origin main
```
